# ft_transcendence

## Overview

**ft_transcendence** is a web-based application project from the 42 curriculum designed to provide a full-stack development experience. The project challenges participants to create a fully functional web application that incorporates both front-end and back-end development, modern web technologies, and advanced features like real-time communication and authentication.

## Features

- **User Authentication**: Secure login and registration with 2FA (Two-Factor Authentication).
- **Real-Time Communication**: Interactive chat with WebSocket implementation.
- **Game Integration**: Classic Pong game with multiplayer capabilities.
- **User Profiles**: Personalized profiles with stats and customization options.
- **Friend System**: Add friends, manage friend requests, and block users.
- **Matchmaking**: Find opponents for real-time Pong matches.
- **Responsive Design**: Fully functional across desktop and mobile devices.
- **Modern Front-End**: Built with a modern framework like React.js or Vue.js.
- **Secure Back-End**: Developed with a robust framework like NestJS or Express.js.

## Tech Stack

- **Front-End**: React.js, HTML5, CSS3, Tailwind
- **Back-End**: Django, Django Rest Frameworks
- **Database**: PostgreSQL/MySQL
- **Authentication**: OAuth2.0, JWT, 2FA
- **Real-Time Communication**: WebSockets
- **Deployment**: Docker, Nginx, CI/CD
